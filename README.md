# AI3 plugins for Claude

Run your AI3 organisation from Claude Code: see what's waiting for you, approve or reject it, put a worker on a job, and talk to your CEO and workers.

```
/plugin marketplace add AI3-co/claude-plugins
/plugin install ai3@ai3
```

- [ai3](ai3/README.md): the AI3 plugin.

Setup guide: https://ai3.co/docs/connect · Support: hello@ai3.co
